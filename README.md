# 📚 Repositório de Provas — FAETERJ



Repositório de provas da FAETERJ, gerenciado pelo Einar, um bot desenvolvido para automatizar o recebimento, a organização e a preservação do acervo.



---



## 📖 Sobre



Este repositório reúne provas de diferentes períodos, disciplinas, professores e semestres, facilitando o acesso a provas de períodos anteriores.



As provas são organizadas de forma padronizada para facilitar a navegação e a preservação do acervo.



---



## 📂 Organização



As provas seguem a estrutura:



```text

Período → Disciplina → Professor → Semestre → Turno → Avaliação

```



Exemplo:



```text

05 - Quinto Período/

└── GPS/

   └── Rosangela de Sena Almeida/

       └── 01 - 2026.2/

           └── Noite/

               └── AV1/

                   └── GPS_AV1_2026-2_Noite_01.pdf

```



### 🔢 Prefixos numéricos



Os prefixos numéricos utilizados nos nomes das pastas têm como objetivo facilitar a organização e a ordenação do acervo no GitHub.



Por exemplo:



```text

01 - Primeiro Período

02 - Segundo Período

03 - Terceiro Período

04 - Quarto Período

05 - Quinto Período

```



Os semestres também utilizam uma numeração sequencial para manter a ordem desejada dentro do diretório:



```text

01 - 2026.2

02 - 2026.1

03 - 2025.2

04 - 2025.1

```



Dessa forma, as pastas são exibidas na ordem mais conveniente para consulta, em vez de depender exclusivamente da ordenação alfabética padrão.

## 📄 Nome dos arquivos



Os arquivos das provas seguem um padrão de nomenclatura que permite identificar rapidamente suas principais informações.



O formato utilizado é:



```text

SIGLA_AVALIACAO_ANO-SEMESTRE_TURNO_NUMERO.extensao

```



Exemplos:



```text

GPS_AV1_2026-2_Noite_01.pdf

GPS_AV1_2026-2_Noite_02.jpg

GPS_AV1_2026-2_Noite_03.png

```



A mesma convenção é utilizada tanto para arquivos PDF quanto para imagens.



### 🔎 Elementos do nome



- **SIGLA** — sigla da disciplina, sem o número correspondente ao período.

- **AVALIAÇÃO** — tipo da avaliação.

- **ANO-SEMESTRE** — semestre em que a avaliação foi aplicada.

- **TURNO** — turno da turma.

- **NÚMERO** — identifica a ordem do arquivo quando uma mesma avaliação possui mais de um arquivo.

- **EXTENSÃO** — formato do arquivo, como `.pdf`, `.jpg` ou `.png`.



### 🎓 Exceção para FAC



Para a disciplina de Fundamentos de Análise de Computadores (FAC), a identificação da turma é utilizada no lugar da sigla da disciplina.



Exemplos:



```text

FAC-A_AV1_2025-1_Noite_01.pdf

FAC-B_AV1_2025-1_Noite_01.pdf

```



Dessa forma, é possível distinguir as provas das diferentes turmas de FAC.

## 📝 Tipos de avaliação



O acervo pode conter os seguintes tipos de avaliação:



- **AV1**

- **AV2**

- **AVS**

- **AVF**



A AVS é sempre vinculada à avaliação que ela substitui, podendo ser uma AV1 ou uma AV2.



Essa relação é indicada no nome da pasta:



```text

AVS (AV1)

AVS (AV2)

```



Os arquivos de uma AVS seguem a mesma convenção de nomenclatura, incorporando a avaliação vinculada:



```text

GPS_AVS-AV1_2026-2_Noite_01.pdf

GPS_AVS-AV2_2026-2_Noite_01.pdf

```
